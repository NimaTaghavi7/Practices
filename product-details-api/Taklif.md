تکلیف: صفحه جزئیات یک محصول

از این API استفاده کنید:

https://fakestoreapi.com/products

یک صفحه بسازید که محصولات را از API دریافت و نمایش دهد.

مرحله ۱ — دریافت اطلاعات

با useEffect و fetch محصولات را بگیرید.

هنگام دریافت اطلاعات Loading... نشان دهید.

در صورت خطا، پیام خطا نمایش دهید.

و فقط محصولات همان دسته نمایش داده شوند.

مرحله ۴ — چالش اصلی

وقتی کاربر روی یک محصول کلیک کرد، اطلاعات همان محصول را از API جداگانه دریافت کنید:

https://fakestoreapi.com/products/1

البته 1 باید با id محصول انتخاب‌شده جایگزین شود.
