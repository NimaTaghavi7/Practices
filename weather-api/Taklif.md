تکلیف امروز: دریافت اطلاعات آب‌وهوا با useEffect و fetch 

یک صفحه ساده بسازید که اطلاعات آب‌وهوای تهران را از API دریافت کند و نمایش دهد.

API:
https://api.open-meteo.com/v1/forecast?latitude=35.69&longitude=51.39&current=temperature_2m,wind_speed_10m

مواردی که باید پیاده‌سازی کنید:

1. وقتی صفحه باز می‌شود، با useEffect اطلاعات API را دریافت کنید.

2. هنگام دریافت اطلاعات، عبارت Loading... را نمایش دهید.

3. بعد از دریافت اطلاعات، موارد زیر را نمایش دهید:
- دمای فعلی
- سرعت باد

4. یک دکمه با عنوان Refresh Weather قرار دهید.
با کلیک روی این دکمه، اطلاعات آب‌وهوا دوباره از API دریافت شود.

5. اگر دریافت اطلاعات با خطا مواجه شد، یک پیام مناسب مثل:
Failed to load weather
نمایش دهید.

6. آخرین زمان دریافت اطلاعات را هم نمایش دهید، مثلاً:
Last updated: 19:42:15

نکته:
تمرکز اصلی این تمرین روی استفاده درست از useEffect و fetch است.

چالش اختیاری:
یک select برای انتخاب شهر اضافه کنید و حداقل ۳ شهر مثل تهران، لندن و مادرید داشته باشید. با تغییر شهر، اطلاعات آب‌وهوا از API مربوط به همان شهر دریافت و نمایش داده شود.

استفاده از Axios یا کتابخانه‌های آماده برای Fetch ممنوع است.
